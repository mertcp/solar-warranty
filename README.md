# Solar warranty demo

Synthetic portfolio monitoring for **heat**, **on-time milestones**, and **performance vs warranty** — so an operator can build a defensible claim file, not a spreadsheet argument.

Status: planning and data model only. See [PROJECT.md](PROJECT.md) for the build checklist and which signals we will implement vs document.

All data is synthetic. No real sites, SCADA exports, or OEM confidential curves.
